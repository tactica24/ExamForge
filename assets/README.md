# Mobile app icon asset

Place your temporary logo file in this folder as one of:
- `assets/logo.png` (recommended)
- `assets/logo.jpg`
- `assets/logo.jpeg`
- `assets/logo.svg`

The Android APK workflow auto-runs:
`npx @capacitor/assets generate --android --assetPath assets`

Recommended source size: 1024x1024 px.
